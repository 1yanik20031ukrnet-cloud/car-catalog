# Car Catalog

**Единый цифровой каталог автосалона**, mobile-first. Салон ведёт
машины в одном месте — в админке, — а клиент видит актуальное наличие,
фильтрует, открывает страницу автомобиля и записывается на просмотр.
Демо-салон в проекте — условный «Premium Cars Warsaw».

Каталог один, а каналов доступа к нему может быть несколько:

- **Web** — публичная ссылка для Instagram, TikTok, Google, QR-кода
  (это то, что работает сейчас);
- **Telegram Mini App** — тот же каталог внутри Telegram (в планах,
  Этап 19 в `TASKS.md`);
- **Web + Telegram** — оба канала поверх одной базы и одной админки.

Web и Telegram — **не два продукта, а два способа доступа к одному
каталогу**: backend, машины, заявки и админка общие.

Отдельно от этого в плане есть **Telegram-бот уведомлений**
(Этап 12) — это не канал для покупателя, а сообщение **сотруднику
салона** о новой заявке. С Mini App не связан и работает без него.

Подробности и архитектурные правила — в `CLAUDE.md`, план — в
`TASKS.md`.

## Стек

- Python 3.14 / Django 6.1
- SQLite (база данных — файл, создаётся автоматически)
- HTML-шаблоны Django + чистый CSS (mobile-first)
- Pillow (работа с загружаемыми фотографиями)

## Запуск проекта локально

1. Клонировать репозиторий и перейти в папку проекта:

   ```
   git clone <адрес-репозитория>
   cd car-catalog
   ```

2. Создать виртуальное окружение и установить зависимости:

   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

   (на Mac/Linux вместо второй строки: `source venv/bin/activate`)

3. Создать базу данных:

   ```
   python manage.py migrate
   ```

4. Создать администратора (для входа в админку):

   ```
   python manage.py createsuperuser
   ```

5. Запустить сервер:

   ```
   python manage.py runserver
   ```

Сайт: http://127.0.0.1:8000/
Админка: http://127.0.0.1:8000/admin/

## Как продукт продаётся

Одна кодовая база → демо-версия для показа салонам → настроенная
версия под конкретный салон (название, логотип, контакты, валюта,
машины, оформление, домен).

**Под каждого клиента — отдельный deployment и отдельная база.**
Несколько салонов внутри одной базы (multi-tenant/SaaS) сейчас
сознательно не делаем — это возможное развитие после первых клиентов.
