# Задачи проекта

Роли (можно менять по договорённости):

- **Ян** — backend: модели, база, фильтры, админка.
- **Друг** — frontend: шаблоны, CSS, карточки, мобильная версия.

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово (замёржено в main).

## Этап 0 — каркас

- [x] Каркас Django-проекта, Git, документация — *Ян* (прямо в `main`,
  это единственное исключение)

## Этап 1 — данные и первый экран (можно делать параллельно)

- [x] **Модели и админка** — *Ян*, ветка `feature/car-models`
  - модели `Dealer`, `Car`, `CarImage`, `Booking` + миграции;
  - регистрация в админке (таблица: фото, автомобиль, цена, статус);
  - демо-данные: 12–16 автомобилей (BMW, Audi, Mercedes, VW, Porsche,
    Volvo) командой `python manage.py seed_demo`;
  - файлы: `cars/models.py`, `cars/admin.py`, `cars/management/`.
- [ ] **Вёрстка каталога** — *Друг*, ветка `feature/catalog-ui`
  - шапка: логотип, название, описание, телефон, Instagram, кнопка
    «Связаться»;
  - сетка карточек автомобиля (пока на тестовых данных прямо в
    шаблоне): фото, марка, модель, год, цена, пробег, топливо,
    коробка, кнопка «Подробнее»;
  - mobile-first, современный «дорогой» минимализм;
  - файлы: `templates/`, `static/css/`.

- [x] **Удобная загрузка фото и внешний вид админки** — *Ян*, ветка
  `feature/admin-usability`
  - одно поле, в котором можно выбрать сразу несколько фотографий;
  - поля формы сгруппированы, служебные скрыты;
  - подключена тема `django-unfold` (тёмная, современная, с цветными
    статусами) — согласовано с владельцем;
  - тема всегда тёмная (без белого светлого варианта), акцентный цвет
    приглушённый серо-синий вместо ярко-фиолетового;
  - ошибки в форме подсвечиваются на самом поле, введённый текст не
    стирается — сбрасываются только выбранные файлы фото (так себя
    ведёт браузер, это не чинится на стороне сайта, только предупреждён
    текстом);
  - поле «Внутренняя заметка» у автомобиля — видно только в админке;
  - файлы: `cars/admin.py`, `cars/models.py`, `config/settings.py`.

- [ ] **Доработка админки (со следующей сессии)** — *Ян*, продолжение
  `feature/admin-usability`
  - Перетаскивание фото: сейчас хватать можно только маленькую иконку
    слева, а сами фото — широкие строки друг под другом на всю
    ширину. Сделать так, чтобы схватить можно было и само фото, и
    область вокруг него, и рассмотреть вариант «фото в ряд» (сеткой
    вместо колонки) — так должно быть нагляднее.
  - Предпросмотр карточки автомобиля и кнопка публикации: после того
    как все поля машины заполнены, показать в админке предпросмотр —
    как машина будет выглядеть на сайте (карточка в каталоге и/или
    страница автомобиля), и отдельную кнопку «Опубликовать на сайт»,
    а не публиковать сразу по нажатию «Сохранить».
    Открытый вопрос на обсуждение при реализации: как это сочетается
    с существующим полем «Статус» (в продаже / зарезервирован /
    продан) — нужно ли отдельное поле «черновик/опубликовано» или
    использовать статус.

Параллельно безопасно: разные файлы. После merge обеих веток
подключаем карточки к реальным данным из базы (небольшая задача,
делает любой из двоих).
